# dfsc-stepaudio（阶跃 StepAudio 语音）

版本 0.3.0。把阶跃 StepAudio TTS 能力接入 DFSC 会话的 MCP 插件。

## 功能

三个工具：

- `text_to_speech`：文本合成语音。支持全局 instruction 定调、句内 `()` 内联语境指令、语速/音量/采样率控制；单次最多 1000 字符。
- `list_voices`：39 个官方音色 + 已复刻音色查询（scope: official/cloned/all）。
- `clone_voice`：5–10 秒参考音频复刻音色（正式复刻 9.9 元/音色；可先试听）。

## 两种模型来源

| 模式 | 凭据 | 前置条件 |
| --- | --- | --- |
| 跟随 DFSC 会话 | **零 Key**，使用当前登录的 Step 账户 | 需含 TTS broker 的宿主构建（上游 #247 合入之后）；首次合成经宿主逐项授权 |
| 独立配置 | 自备 Step Plan 订阅或阶跃开放平台 API Key | 插件中心设置页填写，Key 由宿主保管 |

两模式失败均不静默互切；宿主启动上下文无效时拒绝调用并提示重启会话，不改用独立配置。跟随模式下 `list_voices`/`clone_voice` 不可用（broker 无音色管理入口），需切回独立配置。

## 安装与配置

插件中心设置页填写：后端模式（Step Plan / 开放平台）、接口地址、默认模型、API Key、输出目录及合成默认值（默认音色/语境/格式）。保存后重启会话生效。卸载只移除资源，不停止已完成合成。

## 依赖与边界

- 运行时仅需 Node.js 20+；市场安装不执行 npm install（自包含单文件 `dist/index.js`，官方 MCP SDK 已打包）。
- 使用外部模型服务会上传文本并消耗套餐额度或按量计费；计费按所配置渠道，不随聊天账户切换；市场收录不等于账户或付费授权。
- 音色复刻按次收费（9.9 元/音色）；参数非法的复刻请求不会产生付费资产。
- 无遥测。跟随模式音频写入宿主数据目录，独立模式写入配置的输出目录。
- 0.3.0 起不含桌面工作区入口（0.2.0 的“语音工坊”已摘除）；文档页随包发布。
