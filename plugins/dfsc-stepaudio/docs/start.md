# 快速开始

**阶跃 StepAudio 语音**把三家能力带进 DFSC 会话：文本转语音、音色查询、音色复刻。装好后不需要记任何命令——直接用自然语言让 Agent 干活。

## 三个工具

| 工具 | 干什么 | 典型说法 |
| --- | --- | --- |
| `text_to_speech` | 文本合成语音，落盘返回文件路径 | “把这段合成语音，用磁性男声，语气温柔点” |
| `list_voices` | 查官方音色和已复刻音色 | “有哪些适合有声书的音色？” |
| `clone_voice` | 上传 5–10 秒参考音频，复刻音色 | “用这段音频复刻一个音色，然后念一句话试试” |

## 三十秒上手

1. **选音色**：问 Agent“推荐几个适合客服的音色”，或去[音色库](voices.md)翻表。
2. **合成**：“用`cixingnansheng`念：智能阶跃，十倍每一个人的可能。”音频写到输出目录，Agent 会告诉你路径。
3. **加戏**：StepAudio 2.5 支持语境控制——全局用 `instruction` 定调，句内用 `()` 括号写提示（括号内容不发音）。写法见[语境配方](recipes.md)。

## 配置

- **DFSC 内**：在插件中心本插件的配置页填写（后端模式、接口地址、默认模型、API Key、输出目录）。Key 由宿主保管，不回显。
- **其他 MCP 客户端**：用环境变量 `STEP_API_KEY` 等直连，详见插件仓库 README。
- 计费按所选渠道（Step Plan 额度或开放平台 Key）独立计算，不随聊天账户切换。

## 常见问题

- **合成失败提示配置错误**：说明还没有可用 Key——按上面“配置”节填写后重载会话。
- **音频写到哪里了**：默认输出目录见配置页；每次合成 Agent 会返回绝对路径。
- **想换音色情绪**：`stepaudio-2.5-tts` / `stepaudio-3-tts` 用 `instruction` 和 `()`；`step-tts-2` / `step-tts-mini` 用情绪/风格标签，让 Agent 帮你选。
