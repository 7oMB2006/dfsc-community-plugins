# 语境配方

StepAudio 2.5 / 3 的杀手功能：**用自然语言导演声音**，而不是选标签。两个档位——

- **全局语境 `instruction`**：定调整段的基调、人设、情绪（`stepaudio-2.5-tts` 上限 200 字符，`stepaudio-3-tts` 上限 500）。
- **文中语境 `()`**：在文本里用圆括号插入句内指令，控制单句的情绪、停顿、气声。**括号内的内容不发音**，只作为指令。

## 官方示例

文本：

```text
（压低声音）喂……你看我手机。（短促吸气）是不是我眼花了？（强装镇定）……算了，肯定是诈骗短信。
```

全局指令：

```text
声音极度紧绷，像在拼命压住快要失控的狂喜；语速快而断续，带明显的压抑感
```

## 写法要点

- **描述状态，不要贴标签**。“克制的悲伤，不哭腔，轻轻发颤”比“悲伤”有效；“试探着撒娇，不是很黏，带一点嘴硬”这类混合意图也能表达。
- **括号管局部，instruction 管整体**：整段基调用 instruction；某一句的转折、气口用 `()`。
- **标点即表演**：省略号、破折号、短句分段都会被演出来，长句一口气反而平。
- **指令别太长**：全局 200 字符（2.5 模型）足够，写多了模型抓不住重点。

## 可直接抄的几句

| 场景 | instruction |
| --- | --- |
| 有声书旁白 | 沉稳叙述，语速偏慢，吐字清晰，有陪伴感 |
| 新闻口播 | 中正平稳，播音腔，重音落在关键信息上 |
| 客服应答 | 亲切自然，语速适中，尾音柔和 |
| 游戏角色 | 慵懒中带警觉，句尾轻挑，偶尔气声 |
| 促销口播 | 情绪饱满有鼓动性，语速偏快，重音强调卖点 |

## 模型差异

| 模型 | 语境控制 | 情绪/风格 | 复刻 |
| --- | --- | --- | --- |
| `stepaudio-2.5-tts` | instruction + `()` | 不支持标签，用自然语言 | 3 秒参考音频 |
| `stepaudio-3-tts` | instruction（≤500 字符）+ `()` | 同上 | 支持 |
| `step-tts-2` | 无 | 11 种情绪、17 种风格、粤语/四川话/日语 | 约 10 秒参考音频 |
| `step-tts-mini` | 无 | 9 种情绪、13 种风格 | 约 10 秒参考音频 |

用 `step-tts` 系列时，直接告诉 Agent 要“高兴一点”“用粤语”，Agent 会转成对应的情绪/语言标签。

## 其他可调参数

语速 `speed`（0.5–2）、音量 `volume`（0.1–2）、采样率 `sample_rate`、输出格式（mp3/wav/flac/opus/pcm）——都可以让 Agent 顺便设置，例如“语速放慢到 0.8，输出 wav”。
