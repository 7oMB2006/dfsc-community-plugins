# 音色库

阶跃 StepAudio 官方音色共 **39 个**（37 个有官方名称与描述，2 个官方未提供详情）。按推荐场景分组，同一音色只出现在第一个命中的分组；完整 ID 列表见文末索引。

**怎么试听**：直接让 Agent 念样本，例如“用磁性男声念一句：智能阶跃，十倍每一个人的可能”；或打开[官方 Demo](https://stepaudiollm.github.io/step-audio-2.5-tts/)逐个听。选定后把音色 ID 告诉 Agent 即可。

**注意**：音色数量与详情以实时接口为准（`list_voices` 工具），本页为内置目录快照。
